# 🎯 UserNeed — Telegram Username Finder

Бот ищет свободные короткие и красивые username'ы в Telegram
через MTProto (без скрапинга и капчи).

Бот: @userneed_bot · Канал: @userneed

## Возможности

- 🎲 **Генератор** — слоговые (`vitoz`), брендовые (`zenix`), статусные (`v_max`),
  случайные (`kxvzq`) и «похожие на …».
- 📋 **Массовая проверка** — до 200 имён за раз, живой прогресс, кнопка остановки.
- ⚡ **HTTP pre-check** через `t.me` + SQLite-кэш — большинство занятых имён
  отсеиваются без MTProto.
- 🔁 **Round-Robin** между несколькими аккаунтами, пауза — пер-сессия.
- 🚦 **Анти-флуд** — FloodWait паркует одну сессию, работают другие.
- 🎯 **Точный статус** — `free` / `fragment` (только за TON) / `taken`.
- 🎟 **Квота** — `USAGE_LIMIT` сеансов на участника (по умолчанию 3),
  хранится в SQLite и переживает рестарт. Списывается только после
  успешного завершения прогона. Админы — безлимит.
- 👀 **Мониторинг** (операторы) — фоновое отслеживание имён, сигнал при освобождении.
- 💬 **Обратная связь** — пользователь пишет, админ отвечает reply.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env                 # заполните BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS
python -m config                     # проверка конфига и предупреждений

python qr_login.py acc1              # QR-логин каждой сессии из SESSION_NAMES
python qr_login.py acc2

python main.py
```

Закрытая бета включена по умолчанию (`BETA_MODE=1`): бот отвечает только
ID из `ADMIN_IDS` и `ALLOWED_USER_IDS`. Остальным показывается их Telegram ID,
чтобы они могли попросить доступ.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | панель управления |
| `/help` | все | регламент |
| `/found` | все | история находок за 30 дней |
| `/cancel` | все | сбросить текущий ввод / остановить прогон |
| `/stats`, `/sessions`, `/today` | операторы | состояние сервиса |
| `/feedback` | операторы | последние обращения |
| `/quota <id>`, `/quota_reset <id>`, `/quota_add <id> <n>` | операторы | управление квотой |
| `/report_now`, `/backup_now` | операторы | сводка / бэкап вручную |

## Данные и бэкапы

Все файлы данных (`*.db`, `*.session`, `logs/`, `backups/`) лежат в `DATA_DIR`
(по умолчанию — корень проекта). Суточный бэкап кладёт в zip базы и `assets/`.
`.env` и `*.session` **по умолчанию исключены** — архив не шифруется, а эти
файлы дают полный доступ к аккаунтам. Включить: `BACKUP_INCLUDE_SECRETS=1`.
