# UserNeed

Telegram-бот для поиска свободных username

Генерирует кандидатов, проверяет их через MTProto и следит за именами, которые освобождаются
Без скрапинга и капчи

---

## Возможности

| Модуль | Что делает |
|---|---|
| **Генератор** | Слоговые (`vitoz`), брендовые (`zenix`), статусные (`v_max`) и словарные имена, оценка и ранжирование кандидатов |
| **Похожие** | Варианты по заданному слову: суффиксы, префиксы, замены |
| **Массовая проверка** | До 200 имён за раз, прогресс в реальном времени |
| **Слежка** | Бот следит за занятым именем и пишет, когда оно освободилось |
| **Перепроверка** | Найденное свободное имя проверяется ещё раз перед выдачей |
| **Лимиты** | 5 бесплатных запусков, у админов безлимит |

## Как работает проверка

1. Проверка формата: длина, допустимые символы
2. Кэш: занятые имена не проверяются повторно
3. HTTP pre-check через `t.me`: основная часть занятых имён отсеивается без обращения к MTProto
4. MTProto: окончательный ответ от Telegram (свободно, занято, продаётся на Fragment, недоступно)
5. Round-Robin между несколькими аккаунтами
6. Анти-флуд: FloodWait паркует одну сессию, остальные продолжают работу

## Быстрый старт

```
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполни .env: BOT_TOKEN, API_ID, API_HASH, ADMIN_IDS
python main.py
```

Нужен Python 3.11 или новее

## Структура

```
main.py          запуск бота
config.py        настройки из .env

```

## Безопасность

- Токен бота, `API_ID`, `API_HASH` и сессии аккаунтов хранятся только локально
- `.env`, `*.session` и базы данных перечислены в `.gitignore` и в репозиторий не попадают
- Если секрет когда-либо попал в коммит, его нужно перевыпустить: удаление файла историю не стирает
